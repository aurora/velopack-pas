# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-10-11

## Context

The project spans two compilers, several platforms and a native dependency.
Reasons behind design choices get lost quickly, especially with several
contributors and AI agents involved.

## Decision

We will record significant decisions as Architecture Decision Records in
`docs/adr/`, using `0000-template.md`. Numbers increase monotonically.
Accepted ADRs are not rewritten; a new ADR supersedes an old one.

## Consequences

Decisions are discoverable and reviewable. Small overhead per decision.
